# OXX 통합 장부

매출·매입을 하나의 구글 스프레드시트에서 관리하기 위한 기록입니다.

- 통합 시트: [OXX 장부](https://docs.google.com/spreadsheets/d/1KymTgEIhU54Z1uBZt8Z5_VfG8zfz8xCEtWXbLbmwdpM/edit)
- 기존 시트(보관용, 수정하지 않음): 매출 `1DSWnLkHfEPRTtnaguSTIH8MyYuPQTI0vRKJN0g9t9gU`, 매입 `1gaf4ZlboCwK-b2KEIA56YW1IYoBxcN6l6pyXVmtaaIs`

## 돈의 흐름
- 계좌: 신한은행 1개, 카드: 우리카드 1개.
- 매출: 대부분 계좌 입금 + 세금계산서 발행. 소량은 매장 카드결제, 계좌이체, 현찰.
- BtoC 주문은 선입금이 원칙 → 결제일이 주문일보다 앞서는 게 정상.
- 매입: 우리카드 결제 또는 현금. 현금은 계좌에서 30~50만원씩 인출해 꽃시장에서 나눠 씀(당일 다 쓰지 않음).
- 매입 품목별 단가 × 배수(3, 3.5)를 참고해 소매가를 정함. 소매가는 참고치이며 실제 판매가가 아님.

## 탭 구성 (완료)
| 탭 | 내용 |
|---|---|
| 월별요약 | 연도 입력 → 월별 BtoC/BtoB/배송비, 현금·카드·계좌이체 매입, 순익, 결제수단별 매출. 확인할 것(결제수단 빈 매출, 세금계산서 빈 BtoB, 보유현금) |
| 매출 | 월(수식), 주문일, 주문자, 구분, 상품금액, 배송비, 합계(수식), 품목(드롭다운: 설정 F열), 수량(비우면 1개), 결제수단, 결제일, 입금자명, 세금계산서, 배송지, 메모 |
| 매입 | 월(수식), 날짜, 매입처, 현금, 카드, 계좌이체, 품목, 단수, 가격, 총 갯수, 개당 가격·배수 참고가(수식), 소매가, 메모. P~T열: ATM 인출 행의 인출액·남은 현금·재입금·대조·키. U열 날짜(자동, 사용자가 만듦): 빈 날짜를 위 날짜로 채움 → 월·월별요약·대조가 이 열을 씀 |
| 현금출납 | ATM 인출·통장 입금 기록 + 기준일 이후 장부상 보유현금 계산, 실제 금액과 차이 |
| 통장내역 / 카드내역 | 은행·카드 엑셀 붙여넣기 → 장부에 같은 금액이 있는지 자동 표시 |
| 설정 | 소매 배수, 현금 기준일·보유현금, 드롭다운 목록(매출 품목 포함), 동그라미 가격 이력(A31:B) |

## 이관 결과 (2026년)
- 매출 122건, 매입 813줄. 합계가 원본과 일치: BtoC 9,559,000 / BtoB 25,382,000 / 현금매입 19,632,950 / 카드매입 4,179,897.
- 기존 매입 시트의 '4' 열은 실제로 3.5배로 계산되고 있었음 → 설정에 3.5로 유지.
- 매출은 4/22까지만 기록돼 있음(5월 이후 미입력).
- 2025년 이전은 이관하지 않음.

## 자동 수집 (Apps Script)
코드는 `apps-script/Code.gs`, 설치 방법은 [설치가이드](설치가이드.md).

- 신한 입출금 문자, 우리카드 승인 문자 → 웹앱(doPost, 토큰 확인) → 통장내역/카드내역
- 신한 거래내역 엑셀, 우리카드 이용대금명세서 엑셀 → 가져오기 탭에 붙여넣기 → 반영 (문자로 들어온 건은 중복 없이 '확인' 처리)
- 설정 탭 분류규칙으로 지출 자동 분류, 현금인출은 현금출납 탭에 자동 기록
- 매출/매입 탭과 금액·날짜로 대조해 '장부 확인' 칸 채움
- 파서 테스트: `node --test tests/parsers.test.js`

9월 우리카드 명세서(59건, 2,322,523원)를 카드내역에 넣어 둠. 장부의 9월 카드매입(1,322,920원)과의 차이는 대부분 교통·주차·공과금·보험 같은 경비.

## 꽃시장 현금 흐름 (2026-10-28 확정, 배포 완료)
- ATM에서 인출 → 꽃시장 현금 매입 → 남은 돈은 ATM에 다시 입금 (2026-10-17부터. 그 전 인출은 대조 칸에 '재입금 전').
- 신한 ATM 문자는 이름 줄이 없음 → 적요·내용이 빈 출금 = 현금인출, 입금 = 현금입금 (가끔 입금에 '이유진'이 찍힘 → '개인'으로 분류되지만 매입 대조는 셈).
- 인출 문자가 오면 매입 탭 시장 날짜 맨 위에 '현금 인출 (ATM)' 행 자동 추가. 저녁 6시 이후 인출은 밤 시장(23:30 개장)용 → 다음 날.
- 대조: 남은 현금 = 인출액 − 시장 날짜 현금 칸 합계, 재입금 = 인출 시각부터 36시간 안의 현금입금(또는 이유진) 중 인출액 이하. 설정 B9 = 재입금 시작일.

## 매출 품목 규칙
- 드롭다운(설정 F열): 동그라미(시그니처), 소중(5만 원 꽃다발), 중대(7만 원 꽃다발), 꽃다발(그 밖의 금액), 플라워박스, 부케(웨딩·촬영), 촬영·스타일링, 공간·행사 장식, 센터피스, 화분·식물, 난, 클래스, 기타.
- 동그라미 가격: 5/6 이전 6만 원, 5/6부터 8만 원 (설정 A31 표). 4/30 에피큐어 차장님 건은 인상 예정이라 8만 원으로 받음.
- 여러 개는 수량 칸에. 금액만 보고 채운 품목은 메모에 '금액으로 자동 분류', 바꾸기 전 이름은 '원래 품목: …'.
- 구분이 비면 월별요약에서 빠짐. BtoC는 선입금이 원칙.
