# OXX 장부 자동화 설치

[OXX 장부](https://docs.google.com/spreadsheets/d/1KymTgEIhU54Z1uBZt8Z5_VfG8zfz8xCEtWXbLbmwdpM/edit)에 스크립트를 붙이고, 아이폰 문자를 시트로 보내는 방법입니다. 처음 한 번만 하면 됩니다. 15분쯤 걸립니다.

## 1. 스크립트 붙여넣기 (PC 권장)

1. OXX 장부 시트를 열고 **확장 프로그램 → Apps Script**를 누릅니다.
2. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](../apps-script/Code.gs) 내용을 통째로 붙여넣습니다.
3. 왼쪽 톱니바퀴(프로젝트 설정) → **"appsscript.json" 매니페스트 파일을 편집기에 표시** 체크 → 편집기로 돌아가 `appsscript.json`을 [`apps-script/appsscript.json`](../apps-script/appsscript.json) 내용으로 바꿉니다.
4. 저장(⌘S / Ctrl+S)합니다.
5. 위쪽 함수 선택에서 `refreshAll`을 고르고 **실행**을 누릅니다.
   - "승인 필요" 창이 뜨면 본인 구글 계정을 고르고 **고급 → (안전하지 않은 페이지로) 이동 → 허용**을 누릅니다. 직접 만든 스크립트라서 나오는 경고입니다.
6. 시트로 돌아가 새로고침하면 메뉴에 **OXX 장부**가 생깁니다.

## 2. 웹앱 배포 (문자 받기용)

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴) → **웹 앱**을 고릅니다.
3. 실행 사용자: **나**, 액세스 권한이 있는 사용자: **모든 사용자**로 두고 **배포**를 누릅니다.
4. 시트에서 **OXX 장부 → 문자 연동 설정 보기**를 누르면 웹앱 주소와 토큰이 나옵니다. 둘 다 아이폰 메모에 복사해 둡니다.
   - 토큰이 맞는 요청만 기록되므로 주소가 알려져도 다른 사람이 장부에 쓸 수 없습니다. 토큰은 다른 사람에게 보내지 마세요.

> 나중에 `Code.gs`를 바꾸면 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 해야 문자 연동에도 반영됩니다.

## 3. 아이폰 단축어 자동화

신한 문자용, 우리카드 문자용으로 자동화를 두 개 만듭니다. 순서는 같습니다.

1. **단축어** 앱 → 아래 **자동화** 탭 → 오른쪽 위 **+** → **메시지**.
2. **메시지 내용에 다음 포함**: 첫 번째는 `신한`, 두 번째는 `우리(` 를 입력합니다.
3. **즉시 실행**을 고르고 (실행 시 알림은 꺼도 됩니다) **다음**.
4. **새로운 빈 자동화** → 동작 추가에서 **URL 콘텐츠 가져오기**를 검색해 넣습니다.
5. 동작을 아래처럼 설정합니다.
   - URL: 2단계에서 복사한 웹앱 주소
   - 방법: **POST**
   - 요청 본문: **JSON**
     - 필드 추가 → 텍스트 → 키 `token`, 값: 복사한 토큰
     - 필드 추가 → 텍스트 → 키 `text`, 값: 변수 **단축어 입력** 을 고른 뒤, 그 변수를 한 번 더 눌러 **내용**으로 바꿉니다.
6. 완료.

문자가 오면 몇 초 뒤 시트의 **문자수신** 탭에 원문이 쌓이고, **통장내역** 또는 **카드내역**에 한 줄이 추가됩니다. 문자수신 탭의 종류가 `인식 못함`이면 그 원문을 알려 주세요.

## 4. 평소 사용법

| 상황 | 할 일 |
|---|---|
| 매출이 생김 | **매출** 탭에 직접 입력 (세금계산서 칸 포함) |
| 꽃시장에서 매입 | **매입** 탭에 직접 입력 (현금/카드/계좌이체 칸 중 하나) |
| 통장·카드 사용 | 문자가 오면 자동 기록. 할 일 없음 |
| ATM 인출 | 자동으로 **현금출납**에 'ATM 인출' 기록 |
| 한 달에 한 번 | 신한 거래내역 엑셀, 우리카드 명세서 엑셀을 열어 전체 선택·복사 → **가져오기** 탭 A1에 붙여넣기 → **OXX 장부 → 가져오기 탭 반영**. 문자로 빠진 건이 채워지고 이미 있는 건은 '확인'만 됩니다 |
| 분류가 비어 있음 | 통장내역 I열, 카드내역 F열에서 드롭다운으로 고르기. 자주 나오는 곳은 **설정** 탭 분류규칙에 키워드를 추가 |
| 빨간 칸(확인 필요) | 장부에 기록이 없다는 뜻. 매출/매입 탭에 기록하고 **OXX 장부 → 분류 다시 적용 + 장부 대조** |
| 통장에 들어온 돈을 매출로 | 통장내역에서 입금 행을 선택 → **OXX 장부 → 선택한 입금을 매출에 추가** |

## 장부 확인 칸의 뜻

- **매출 있음 / 매입 있음**: 같은 금액의 기록이 장부에 있음 (매입은 날짜 ±3일, 매출은 결제일 ±3일 또는 주문일 기준 60일 전~30일 후)
- **일 합계 일치**: 카드 결제를 여러 번 나눠 했지만 그날 합계가 매입 탭과 같음
- **매출 확인 필요 / 매입 확인 필요**: 장부에서 못 찾음
- **분류 필요**: 분류가 비어 있음
- **경비**: 매입이 아닌 지출 (교통, 주차, 공과금 등). 월별요약 아래쪽 표에 분류별로 합산
- **현금출납 반영**: 현금 인출이 현금출납 탭에 기록됨
