# OXX 장부 자동화 설치

[OXX 장부](https://docs.google.com/spreadsheets/d/1KymTgEIhU54Z1uBZt8Z5_VfG8zfz8xCEtWXbLbmwdpM/edit)에 스크립트를 붙이고, 아이폰 문자를 시트로 보내는 방법입니다. PC 브라우저에서 순서대로 하면 15분쯤 걸립니다.

---

## 1단계. Apps Script 열기

1. OXX 장부 시트를 엽니다.
2. 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다.
3. 새 탭으로 편집기가 열리고, 왼쪽 파일 목록에 `Code.gs`가 있습니다. 오른쪽에는 `function myFunction() { }`이 적혀 있습니다.

## 2단계. 코드 붙여넣기

1. 새 탭에서 아래 주소를 엽니다. 코드만 글자로 보이는 페이지입니다.
   **https://raw.githubusercontent.com/oxxfloral/finance/main/apps-script/Code.gs**
2. 그 페이지에서 **Ctrl+A**(전체 선택), **Ctrl+C**(복사)를 누릅니다. 맥은 ⌘A, ⌘C입니다.
3. Apps Script 탭으로 돌아와 편집기 안을 한 번 클릭합니다.
4. **Ctrl+A**를 누른 뒤 **Ctrl+V**를 누릅니다. 원래 있던 `myFunction`이 지워지고 코드로 바뀝니다.
5. **Ctrl+S**로 저장합니다. 위쪽 파일 이름 옆의 주황 점이 사라지면 저장된 것입니다.

## 3단계. 설정 파일 바꾸기

1. 왼쪽 맨 아래 **톱니바퀴(프로젝트 설정)**를 누릅니다.
2. **"appsscript.json" 매니페스트 파일을 편집기에 표시**에 체크합니다.
3. 왼쪽 맨 위 **<> (편집기)** 아이콘을 눌러 돌아오면 파일 목록에 `appsscript.json`이 생겨 있습니다. 그 파일을 누릅니다.
4. 안의 내용을 모두 지우고 아래를 그대로 붙여넣은 다음 **Ctrl+S**로 저장합니다.

```json
{
  "timeZone": "Asia/Seoul",
  "runtimeVersion": "V8",
  "exceptionLogging": "STACKDRIVER",
  "webapp": {
    "executeAs": "USER_DEPLOYING",
    "access": "ANYONE_ANONYMOUS"
  }
}
```

## 4단계. 한 번 실행해서 권한 승인

1. 왼쪽에서 `Code.gs`를 다시 누릅니다.
2. 위쪽 도구줄의 **▷ 실행** 옆 함수 선택 칸을 눌러 **`refreshAll`**을 고릅니다.
3. **▷ 실행**을 누릅니다.
4. "승인 필요" 창이 뜨면 아래 순서로 누릅니다.
   - **권한 검토** → 본인 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 화면에서 왼쪽 아래 **고급** → **OXX 장부(으)로 이동(안전하지 않음)**
   - **허용**

   직접 만든 스크립트라서 나오는 경고라 괜찮습니다.
5. 아래 실행 로그에 "실행 완료"가 뜨면 성공입니다.

## 5단계. 메뉴 확인

1. 시트 탭으로 돌아가 **새로고침(F5)**을 합니다.
2. 몇 초 뒤 메뉴줄에 **OXX 장부**가 생깁니다.
3. **OXX 장부 → 분류 다시 적용 + 장부 대조**를 누릅니다. 통장내역·카드내역의 '장부 확인' 칸이 채워지면 정상입니다.

여기까지 하면 엑셀 가져오기와 대조 기능을 쓸 수 있습니다. 아래는 문자 자동 기록을 위한 설정입니다.

---

## 6단계. 웹앱으로 배포

1. Apps Script 탭 오른쪽 위 파란 **배포** → **새 배포**를 누릅니다.
2. "유형 선택" 옆 **톱니바퀴** → **웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.
   - 설명: `문자 연동` (아무거나 적어도 됩니다)
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누릅니다. 권한 창이 또 뜨면 4단계처럼 허용합니다.
5. 시트로 돌아가 **OXX 장부 → 문자 연동 설정 보기**를 누릅니다.
6. 창에 나온 **웹앱 주소**(`https://script.google.com/macros/s/.../exec`)와 **토큰**(32자리 영문·숫자)을 복사해 둡니다. 아이폰으로 옮겨야 하니 카톡 나에게 보내기나 메모 앱이 편합니다.
   - 토큰은 다른 사람에게 보내지 마세요. 토큰이 맞는 요청만 기록되므로 주소가 알려져도 다른 사람이 장부에 쓸 수 없습니다.

## 7단계. 아이폰 단축어 자동화 (신한 문자)

1. **단축어** 앱을 열고 아래 **자동화** 탭을 누릅니다.
2. 오른쪽 위 **+** → **메시지**를 고릅니다.
3. **메시지 내용에 다음 포함** → `신한`을 입력합니다. 보낸 사람은 비워 둡니다.
4. 아래 **즉시 실행**을 고르고, **실행 시 알림**은 끕니다 → **다음**.
5. **새로운 빈 자동화**를 누릅니다.
6. **동작 추가**에서 `URL`을 검색해 **URL 콘텐츠 가져오기**를 누릅니다.
7. 동작 안의 파란 **URL** 글자를 눌러 6단계에서 복사한 웹앱 주소를 붙여넣습니다.
8. 동작 옆 **>** 화살표를 눌러 펼친 뒤 아래처럼 바꿉니다.
   - 방법: **POST**
   - 요청 본문: **JSON**
9. **새로운 필드 추가 → 텍스트**를 누릅니다.
   - 키: `token`
   - 텍스트: 복사한 토큰 붙여넣기
10. 다시 **새로운 필드 추가 → 텍스트**를 누릅니다.
    - 키: `text`
    - 텍스트 칸을 누르면 키보드 위에 변수 목록이 나옵니다. **단축어 입력**을 고릅니다.
    - 들어간 **단축어 입력**을 한 번 더 눌러 목록에서 **내용**으로 바꿉니다.
11. 오른쪽 위 **완료**를 누릅니다.

## 8단계. 아이폰 단축어 자동화 (우리카드 문자)

7단계를 그대로 한 번 더 합니다. 3번에서만 `신한` 대신 **`우리(`**를 입력합니다. 괄호까지 넣어야 다른 '우리' 문자와 섞이지 않습니다.

## 9단계. 확인

다음에 신한이나 우리카드 문자가 오면 몇 초 뒤 시트를 확인합니다.
- **문자수신** 탭에 원문이 한 줄 생깁니다.
- **통장내역**이나 **카드내역**에 그 거래가 추가됩니다.

문자수신 탭의 종류가 **인식 못함**이면 그 원문을 알려 주세요. 아무것도 안 생기면 7~8단계 설정 화면을 캡처해 주세요.

> 나중에 코드를 바꿀 때는 2단계처럼 다시 붙여넣고 저장합니다. 그다음 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 해야 문자 연동에도 반영됩니다. 웹앱 주소와 토큰은 바뀌지 않습니다.

## OXX 장부 메뉴

스크립트를 설치하면 시트 메뉴줄(확장 프로그램, 도움말 근처)에 생깁니다. PC 브라우저에서만 보이고, 휴대폰 구글 시트 앱에는 나타나지 않습니다.

| 항목 | 하는 일 |
|---|---|
| **가져오기 탭 반영 (통장/카드 엑셀)** | 가져오기 탭에 붙여넣은 신한 거래내역이나 우리카드 명세서를 통장내역·카드내역에 옮깁니다. 끝나면 가져오기 탭을 비웁니다. |
| **분류 다시 적용 + 장부 대조** | 비어 있는 분류를 규칙으로 채우고, '장부 확인' 칸을 새로 계산합니다. |
| **선택한 입금을 매출에 추가** | 통장내역에서 고른 입금 행을 매출 탭에 새 행으로 넣습니다. |
| **문자 연동 설정 보기** | 아이폰 단축어에 넣을 웹앱 주소와 토큰을 보여줍니다. |

### 엑셀 반영 순서 (한 달에 한 번)
1. 신한 거래내역이나 우리카드 명세서 엑셀 파일을 열고 전체 선택(Ctrl+A) 후 복사합니다.
2. OXX 장부의 **가져오기** 탭에서 A1 칸을 누르고 붙여넣습니다.
3. **OXX 장부 → 가져오기 탭 반영 (통장/카드 엑셀)**을 누릅니다.
4. "새로 ○건, 이미 있던 ○건 확인" 창이 뜨면 끝입니다. 문자로 이미 들어온 건은 중복으로 넣지 않습니다.

## 평소 사용법

| 상황 | 할 일 |
|---|---|
| 매출이 생김 | **매출** 탭에 직접 입력 (세금계산서 칸 포함) |
| 꽃시장에서 매입 | **매입** 탭에 직접 입력 (현금/카드/계좌이체 칸 중 하나) |
| 통장·카드 사용 | 문자가 오면 자동 기록. 할 일 없음 |
| ATM 인출 | 자동으로 **현금출납**에 'ATM 인출' 기록 |
| 분류가 비어 있음 | 통장내역 I열, 카드내역 F열에서 드롭다운으로 고르기. 자주 나오는 곳은 **설정** 탭 분류규칙(G:H열)에 키워드 추가 |
| 빨간 칸(확인 필요) | 장부에 기록이 없다는 뜻. 매출/매입 탭에 기록하고 **분류 다시 적용 + 장부 대조** |
| 통장에 들어온 돈을 매출로 | 통장내역에서 입금 행 선택 → **선택한 입금을 매출에 추가** |

## 장부 확인 칸의 뜻

- **매출 있음 / 매입 있음**: 같은 금액의 기록이 장부에 있음 (매입은 날짜 ±3일, 매출은 결제일 ±3일 또는 주문일 기준 60일 전~30일 후)
- **일 합계 일치**: 카드 결제를 여러 번 나눠 했지만 그날 합계가 매입 탭과 같음
- **매출 확인 필요 / 매입 확인 필요**: 장부에서 못 찾음
- **분류 필요**: 분류가 비어 있음
- **경비**: 매입이 아닌 지출 (교통, 주차, 공과금 등). 월별요약 아래쪽 표에 분류별로 합산
- **현금출납 반영**: 현금 인출이 현금출납 탭에 기록됨

## 아직 남은 일

- 카드내역 F열 분류 비어 있는 9월 건: 대성기획(5건), 노가든 150,000, 가람국시, 주식회사 제일 76,592, 와이유마트, 티앤에스트레이딩, 구글플레이
- 통장내역 I열: 이진호 850,000, 박주성(프로파벽) 88,000
- 설정 탭: 현금 기준일과 그날 보유현금 입력
- 매출 탭: 5월 이후 매출 입력 (통장내역 입금을 '선택한 입금을 매출에 추가'로 옮기면 편함), BtoB 세금계산서 칸 채우기
- 신한 ATM 출금 문자 형식 확인 (`CD출금`/`ATM`이 아니면 설정 분류규칙에 추가)
- 저장소 기본 브랜치를 `main`으로 바꾸기, 필요하면 Private으로 전환 (GitHub Settings)
